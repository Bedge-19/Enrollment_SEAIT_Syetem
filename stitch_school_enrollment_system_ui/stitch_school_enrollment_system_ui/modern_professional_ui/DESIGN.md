## Brand & Style

The design system delivers an executive, disciplined, and uncompromisingly clear operational workspace. Tailored for enterprise dashboards, administrative pipelines, and rigorous transactional workflows, the identity prioritizes immediate legibility, high task velocity, and structural clarity over ornamental styling.

The visual style is **Corporate / Modern** distilled to pure functional utility. It pairs crisp pure white surfaces with precise, neutral structural boundaries and an active orange accent (`#ea580c`) reserved strictly for focal actions and active progress cues. Every screen rejects unnecessary decorative illustrations, gratuitous blurs, and heavy shadows in favor of balanced typography, consistent vertical rhythms, and clean border separations.

## Colors

The palette is engineered around an immaculate pure white foundation (`#ffffff`) paired with neutral cool slate tones and a high-visibility orange accent (`#ea580c`).

- **Canvas & Backgrounds:** The base canvas is `#ffffff`. Alternate panels and secondary container backgrounds utilize `#f8fafc` or `#f1f5f9` to establish clean separation without resorting to heavy shadow layers.
- **Primary Accent (`#ea580c`):** Utilized strictly for primary interaction targets, completed checkpoints, key navigation badges, and critical state indicators. It communicates active focus and immediate utility.
- **Neutrals & Structure:** High-contrast text uses `#0f172a` for maximum readability. Secondary and label copy uses `#475569` and `#64748b`. Standard structural borders use a crisp hairline `#e2e8f0`, with `#cbd5e1` for active inputs or secondary button perimeters.
- **Status Indicators:** Conventional semantic colors provide immediate, unambiguous system state comprehension (Emerald `#047857` on `#ecfdf5`, Amber `#b45309` on `#fffbeb`, and Red `#b91c1c` on `#fef2f2`).

## Typography

The typography standardizes entirely on **Arial** (`Arial, Helvetica, sans-serif`). By relying on a universal, neutral, and highly legible system sans-serif, the interface avoids stylistic idiosyncrasies and guarantees zero-latency rendering across all platforms.

- **Legibility & Weights:** Hierarchy is built through explicit scale steps and weight contrast (Regular `400` vs. Bold `700`). Headline sizes maintain tight leading to keep headers crisp, while body copy maintains comfortable leading for rapid scanning.
- **Tabular Data:** All numeric representations in tables, key performance indicators, timestamps, and balance figures must specify `font-variant-numeric: tabular-nums` to ensure exact column alignment.
- **Capitalization:** Form labels and column headers avoid exaggerated letter-spacing, relying on `label-md` and `label-sm` with natural sentence or standard title casing for clean readability.

## Layout & Spacing

The layout model is constructed on a 12-column fluid grid system bounded by a max-width container of `1440px`. The system strictly abides by an `8px` spatial grid (`0.5rem`), with a `4px` half-step (`0.25rem`) for compact component interiors.

- **Desktop (1024px+):** 12 columns, `1.5rem` (`24px`) gutters, `2rem` (`32px`) margins. Side navigation bars are fixed at standard widths (`240px` to `280px`), while the main canvas dynamically accommodates multi-pane records and analytical dashboards.
- **Tablet (768px – 1023px):** 8 columns, `1rem` (`16px`) gutters, `1.5rem` (`24px`) margins. Toolbars and multi-column inputs collapse to 2-column or full-width groups.
- **Mobile (< 768px):** 4 columns, `1rem` (`16px`) gutters, `1rem` (`16px`) margins. Tabular grids transition to stacked data cards.
- **Padding Discipline:** Spacing between atomic elements (e.g., label to field) uses `space-xs` (`4px`) or `space-sm` (`8px`). Card inner padding relies uniformly on `space-lg` (`24px`) on desktop and `space-md` (`16px`) on compact devices.

## Elevation & Depth

Visual depth is achieved through **low-contrast outlines** and subtle tonal surfaces rather than heavy drop shadows. This preserves a flat, crisp, and high-efficiency visual baseline.

- **Layer 0 (Canvas):** Pure `#ffffff` base plane.
- **Layer 1 (Cards & Modules):** Sitting on `#ffffff`, cards and containers use a crisp `1px solid #e2e8f0` border. Shadows are omitted or kept to an ultra-faint structural tint: `0 1px 2px 0 rgba(15, 23, 42, 0.05)`.
- **Layer 2 (Dropdowns & Popovers):** Context menus, select drawers, and datepickers use `#ffffff` backgrounds, a `1px solid #cbd5e1` perimeter, and a subtle floating shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Layer 3 (Modal Overlays):** Modal viewports sit above a neutral translucent scrim (`rgba(15, 23, 42, 0.45)`), defined by a `1px solid #cbd5e1` frame with an elevation shadow of `0 10px 15px -3px rgba(15, 23, 42, 0.1)`.

## Shapes

The design system adopts a **Soft (Level 1)** geometric standard. This geometry projects professional discipline, modern cleanliness, and structure while avoiding aggressive sharp edges or playful, oversized radii.

- **Controls & Inputs:** Buttons, text fields, checkboxes, and select menus utilize `0.25rem` (`4px`) to `0.375rem` (`6px`) corners.
- **Cards & Panes:** Standard panels, data tables, and modal windows employ `0.5rem` (`8px`) corner radii (`rounded-lg`).
- **Pills & Badges:** State chips, counter badges, and notification tags apply full circular radii (`9999px`) to create clear formal differentiation from actionable buttons and interactive containers.

## Components

### Buttons
- **Primary:** Solid `#ea580c` fill, `#ffffff` text, font weight `700`, `height: 38px`, padding `0 16px`, radius `4px`. Hover state: `#c2410c`. Active: `#9a3412`. Focus ring: `2px solid #ea580c` with `2px` offset.
- **Secondary:** Surface `#ffffff`, `1px solid #cbd5e1` border, `#0f172a` text. Hover state: `#f8fafc` background with `#0f172a` border.
- **Tertiary / Ghost:** Transparent background, `#475569` text. Hover state: `#f1f5f9` fill with `#0f172a` text.

### Input Fields & Controls
- **Text Inputs & Selects:** `#ffffff` background, `height: 38px`, border `1px solid #cbd5e1`, radius `4px`, padding `0 12px`. Text `#0f172a`, placeholder `#94a3b8`. Focus state: border turns `#ea580c` with a sharp `1px` outline ring.
- **Checkboxes & Radios:** `16px x 16px`, `1px solid #cbd5e1` border, `#ffffff` base. When checked: `#ea580c` background with crisp white checkmark or inner dot.

### Cards & Panels
- Constructed with `#ffffff` backgrounds and a perimeter border of `1px solid #e2e8f0`. Border radius is `8px`. Padding is `20px` to `24px`. Header sections are separated from card bodies by a clean `1px solid #e2e8f0` divider line.

### Data Tables
- **Header:** Background `#f8fafc`, height `40px`, text in `#475569`, font size `12px`, weight `700`, bordered with `1px solid #e2e8f0` at the bottom.
- **Rows:** Background `#ffffff`, height `48px`, border bottom `1px solid #f1f5f9`. Row hover transitions smoothly to `#f8fafc`. All metrics and IDs render using tabular numerals.

### Status Indicators & Chips
- Compact height (`22px`), pill radius (`9999px`), padding `2px 10px`, font size `11px`, weight `700`.
- **Active / Primary:** `#ea580c` text on `#fff7ed` background with a `1px solid #fed7aa` border.
- **Success:** `#047857` text on `#ecfdf5` background with a `1px solid #a7f3d0` border.
- **Warning:** `#b45309` text on `#fffbeb` background with a `1px solid #fde68a` border.
- **Error:** `#b91c1c` text on `#fef2f2` background with a `1px solid #fecaca` border.
