## Brand & Style
The design system delivers an authoritative, energetic, and deeply institutional experience tailored for higher education admissions teams, registrars, and applicant cohorts. The identity balances executive-tier clarity with motivational momentum: university administration requires rock-solid data integrity, while prospective students require an encouraging, clear path through complex bureaucratic processes.

The visual style is **Corporate / Modern** elevated by precise editorial craftsmanship. It prioritizes pristine whites, structural slate neutrals, and a signature warm flame-orange accent that signals warmth, vitality, and institutional pride. Visual noise is aggressively eliminated in favor of razor-sharp hairline dividers, crisp tabular layouts, and clear typographic hierarchy, avoiding sterile corporate coldness while maintaining operational rigor.

## Colors
The color architecture establishes an immaculate, light-first canvas where actionable workflows and status milestones command immediate recognition.

- **Canvas & Surfaces:**
  - Base Background: `#FAFAFA`
  - Elevated Surface / Card Background: `#FFFFFF`
  - Subtle Surface Alt / Table Header: `#F8FAFC`
- **Primary Palette:**
  - Primary Base (`#EA580C`): Core interactive CTA elements, active navigational states, and high-priority indicators.
  - Primary Vibrant (`#F97316`): Hover states, interactive highlights, and focal progress markers.
  - Primary Subtle Tint (`#FFF7ED`): Interactive selections, soft tag backgrounds, and highlighted active table rows.
- **Secondary & Accent Palette:**
  - Secondary Amber (`#F59E0B`): Milestone indicators, financial aid notifications, and secondary badges.
  - Secondary Tint (`#FEF3C7`): Pending review tags and warning banner fills.
- **Neutrals (Slate Tiers):**
  - High-Contrast Text / Headlines: `#0F172A`
  - Body & Form Labels: `#334155`
  - Secondary Text / Metadata / Icons: `#64748B`
  - Crisp Borders / Dividers: `#E2E8F0`
  - Soft Sub-borders / Hover Outlines: `#CBD5E1`
- **Functional Status Indicators:**
  - Cleared / Admitted / Verified: Emerald (`#10B981` text/icon, `#ECFDF5` container fill)
  - Action Required / Under Review: Amber (`#F59E0B` text/icon, `#FFFBEB` container fill)
  - Incomplete / Withdrawn / Rejected: Rose (`#F43F5E` text/icon, `#FFF1F2` container fill)

## Typography
The system employs a dual-typeface strategy pairing **Hanken Grotesk** for display headers and section signposts with **Inter** for data-dense tables, application fields, and continuous reading.

- **Hanken Grotesk** conveys contemporary institutional prestige. Its clean geometric cuts and robust letterforms ground high-level enrollment statistics, dashboard headers, and cohort banners.
- **Inter** handles high-volume administrative data. With neutral curves, wide aperture, and optimized legibility at micro scales (11px–14px), it ensures seamless scanning of transcripts, course codes, and audit logs.
- All numbers within tables, tuition balances, and GPA fields must enforce tabular lining figures (`font-variant-numeric: tabular-nums`) to preserve vertical column alignment across rows.

## Layout & Spacing
The layout implements a rigid 12-column fluid grid system pinned to a maximum canvas width of `1536px` to avoid over-stretching wide data views on ultra-wide desktop monitors.

- **Desktop (1024px and above):** 12 columns, `1.5rem` (`24px`) gutters, `2rem` (`32px`) screen margin. Multi-step enrollment forms use an offset 8-column center flow with sticky contextual rail cards occupying the remaining 4 columns.
- **Tablet (768px - 1023px):** 8 columns, `1rem` (`16px`) gutters, `1.5rem` (`24px`) margins. Sidebar navigations compress into an icon-rail or collapsible off-canvas drawer.
- **Mobile (< 768px):** 4 columns, `1rem` (`16px`) gutters, `1rem` (`16px`) screen margins. Tables shift to card-based record stacks, and multi-step forms anchor step indicators to a compact top breadcrumb bar.
- Spacing rhythm strictly follows multiples of `4px` (`0.25rem`), keeping input labels, form groups, and nested summary cards aligned on an uninterrupted baseline.

## Elevation & Depth
Elevation is achieved using sharp hairline boundaries paired with ambient, highly diffused slate shadows, completely eschewing harsh drop shadows.

- **Flat / Base Level:** The `#FAFAFA` canvas acts as the lowest plane. Form inputs and background regions rest directly on this ground.
- **Card & Container Tier (Elevation 1):** Main content cards, admissions rosters, and data blocks sit on `#FFFFFF`, framed with a uniform `1px solid #E2E8F0` border and an ultra-subtle ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`.
- **Floating Overlays & Popovers (Elevation 2):** Context menus, candidate action sheets, and dropdown selectors carry a crisp `1px solid #E2E8F0` outline and a soft float shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.06), 0 4px 6px -4px rgba(15, 23, 42, 0.04)`.
- **Modals & Dialogs (Elevation 3):** Modal overlays employ a backdrop filter (`backdrop-blur-sm` over `rgba(15, 23, 42, 0.40)`) with cards enclosed in a 1px border and deep ambient support: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`.

## Shapes
The shape strategy balances modern warmth with institutional discipline. 

- Interactive controls (buttons, text inputs, select dropdowns) use a consistent `0.5rem` (`8px`) border radius.
- Primary card surfaces, modal sheets, and data table housings apply `rounded-xl` (`1.5rem` / `24px`), giving major operational views an inviting, polished architecture without sacrificing screen real estate.
- Small contextual chips, status pills, and counter badges use pill radii (`9999px`) to immediately separate metadata tags from structural buttons and interactive inputs.

## Components

### Buttons
- **Primary:** Solid `#EA580C` background, white text (`#FFFFFF`), `font-weight: 500`. Hover state brightens to `#F97316`. Active state shifts to `#C2410C`. Focus rings feature `2px` offset with `#EA580C` ring.
- **Secondary / Outline:** White `#FFFFFF` background, `1px solid #E2E8F0` border, `#334155` text. Hover transitions to `#F8FAFC` background with `#0F172A` text and `#CBD5E1` border.
- **Destructive:** Light crimson background (`#FFF1F2`), `#F43F5E` text, `1px solid #FECDD3`. Hover transitions to solid `#F43F5E` with `#FFFFFF` text.
- Dimensions: Height `40px` (standard), `32px` (compact table row actions). Radius `0.5rem`.

### Form Inputs & Multi-Step Wizard
- **Text Fields & Selects:** Height `42px`, `#FFFFFF` fill, `1px solid #E2E8F0` border, `0.5rem` radius. Text is `#0F172A`, placeholder is `#94A3B8`. Active focus triggers a crisp `#EA580C` border with an ambient `3px` glow (`rgba(234, 88, 12, 0.12)`).
- **Multi-Step Step Tracker:** Connected horizontal line in `#E2E8F0`. Completed steps use a solid `#10B981` check circle; the current step uses `#EA580C` with a white inner dot and bold label; upcoming steps use an `#E2E8F0` ring with `#64748B` label.

### Academic Data Tables
- **Container:** Enclosed in a `rounded-xl` card (`1.5rem` radius) with `1px solid #E2E8F0` overflow clip.
- **Header:** Background `#F8FAFC`, height `44px`, uppercase `label-sm` typography in `#64748B`, bottom hairline divider `1px solid #E2E8F0`.
- **Rows:** Alternating subtle hover states (`#FFF7ED`/30% or `#F8FAFC`). Height `52px` to accommodate dense student records comfortably. Cells utilize tabular numerals for metrics like GPA, credit counts, and dates.
- **Sticky Actions:** Rightmost action cell sticks on horizontal scroll with a subtle vertical boundary shadow.

### Status Chips & Badges
- Displayed with a pill radius (`9999px`), `12px` font size, `font-weight: 600`, and an inner `6px` status dot.
- **Approved / Cleared:** `#ECFDF5` background, `#047857` text, `#10B981` dot.
- **Pending / In Review:** `#FFFBEB` background, `#B45309` text, `#F59E0B` dot.
- **Rejected / Action Blocked:** `#FFF1F2` background, `#BE123C` text, `#F43F5E` dot.

### Checkboxes & Radio Controls
- Base: `18px` width and height, `#FFFFFF` background, `1px solid #CBD5E1`.
- Checked: `#EA580C` fill with white checkmark or inner dot. Focus visible: `2px` ring `#F97316` at `2px` offset.

### Cards
- Constructed with `#FFFFFF` background, `rounded-xl` (`1.5rem` / `24px`) perimeter, `1px solid #E2E8F0`, and `1.5rem` internal padding. Card headers include an optional bottom hairline divider (`1px solid #F1F5F9`) to clearly segment summary metrics from granular actions.
